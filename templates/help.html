CampusFix help

CampusFix is a standalone campus services application. It does not connect to Chania or any university production system.

Download the user and deployment guide

Students and lecturers

  1. Create an account and sign in.
  2. Use the dashboard to report and track a facilities issue.
  3. Open Campus services to post lost/found notices or request a vehicle sticker.
  4. Check notifications for staff decisions and progress updates.

Technicians and supervisors

Technicians use their dashboard to open assigned tickets, add work notes and update repair status. Supervisors review new tickets, set priority/deadline, assign active technicians, and review lost-item matches and vehicle sticker requests in Campus services.

Administrators

The admin panel manages users and campus catalogs, and provides reports and audit records. Database backups are generated once per day when the application starts; use the Database backup link to download the latest backup.

Account recovery and security

Use “Forgot your password?” on the login page to request a reset link. Email delivery requires the SMTP settings described in the deployment guide. Supervisors and administrators can enroll an authenticator app from Security.
